# ACR Companion 评审人员使用手册

**适用版本：** v0.6.7（Build 48）。您所使用的版本显示在【关于】页面。
**更新日期：** 2026 年 9 月 18 日
**状态：** 已获 CRIL 批准用于本次受邀评估，不对外公开发布。
**适用对象：** 受邀的临床评审人员及评审测试人员。
**英文版：** ACR_Companion_User_Manual_EN。

---

## 1. 阅读前须知

- **仅限合成数据。** 切勿输入任何真实患者的信息，包括经过编码或假名化处理的信息。本应用不要求输入姓名或病历号。
- **不用于临床。** 结果仅为评估用途的决策支持，不得用于任何人的诊断或治疗。
- **应用本身不含任何临床规则。** 结果中的所有内容均来自 ACR 平台。应用只负责收集您的输入、安全发送，并显示返回结果。
- **规则如何运作**（分子亚型、风险、治疗方案、贝叶斯置信度）详见配套文件《ACR Companion — ZZU 评审人员审核与测试清单》。本手册只说明如何使用应用。

本手册中，【】内的文字为应用中文界面上按钮和页面的原文。

## 3. 安装应用

**CRIL 会告知您本人手机的安装方式。** 请只安装 CRIL 发送给您的文件或链接。

**Android**
1. 打开 CRIL 发送的安装文件（以 `.apk` 结尾）。
2. 如手机提示，请允许从该来源（例如浏览器或文件管理器）安装。部分手机（如小米、三星）会显示额外的安全提示，请选择继续安装。
3. 安装完成后，打开 **ACR Companion**。

**iPhone**
iPhone 的安装由 CRIL 另行安排。首次打开时，iPhone 可能要求您信任开发者：请前往「设置 → 通用 → VPN 与设备管理」并选择信任。

如手机上已安装旧版本，CRIL 会告知您直接覆盖更新，还是先删除旧版本。

## 5. 打开应用并选择语言

1. 打开应用，首先进入【评估访问】页面。
2. 如需切换语言，点击【返回】进入欢迎页，点击【语言】并选择。所有页面将随之切换；阿拉伯语为从右向左显示。
3. 欢迎页还有【关于】按钮，介绍 ACR 平台并显示应用版本。
4. 在欢迎页停留几秒后，会出现一页介绍海报。左右滑动可查看【隐私与 Cookies】声明，其中的【阅读详情】可在手机上打开本手册。向上滑动即可继续。
5. 点击【我已了解 — 开始】返回【评估访问】。

## 6. 首次连接

1. 在【评估访问】页面的【邀请码】中输入您的邀请码。
2. 点击【安全连接】。
3. 应用显示确认信息：「邀请码已接受，并已与本移动设备配对，仅限本设备使用。有效期 30 天。」同时显示配对时间和到期时间（UTC）。点击【继续】。
4. 点击【下一步】开始评估。

**请注意：**
- **邀请码仅限一部手机使用。** 首次输入邀请码的手机即与之配对。在其他手机上输入时，应用会提示「设备不正确。此设备未获此邀请码授权。」
- **有效期为配对后 30 天。** 到期后应用提示「邀请码已过期。请申请新的邀请码。」请向 CRIL 申请新的邀请码。
- **邀请码只需输入一次。** 之后每次打开应用都会自动重新连接。只有在【断开访问】之后（见第 12 节）才需重新输入，且 30 天有效期不会重新计算。
- 邀请码本身绝不会保存在手机上。

### 连接状态面板
同一页面的【连接证据】显示：
- **【网关】：**【已连接】、【服务器未连接】或【正在检查…】
- **【基线证明】：**【已验证】表示 ACR 平台正是经批准的版本，可以生成实时结果；【不匹配】或【不可用】表示实时结果被阻止。

## 7. 实时平台与合成演示

开始前，请在【交付模式】中选择：

| 选项 | 效果 | 适用场合 |
|---|---|---|
| **【实时平台】**（蓝色） | 您的输入发送到 ACR 平台，由平台即时应用临床规则 | 所有正式测试病例 |
| **【合成演示】**（琥珀色） | 不运行任何规则。应用自动填入一个固定的演示病例，服务显示此前由实时平台针对该病例记录的结果 | 快速查看完整结果的样式，或实时平台离线时使用 |

在演示模式下，**请勿修改任何数值**。一旦修改，【复核】页面会显示红色的【演示病例已修改】提示框，且不会返回结果。

## 8. 输入病例

### 一般说明
- **必填项：** 仅第 1 屏的 ER、PR、HER2 和 Ki-67。Ki-67 填入 0 至 100 的数值之前，【下一步】不可用。
- **其余项均为选填，** 但部分项标有【完整评估所需】。缺少这些数值时，平台仍会返回结果，但不显示风险（见第 10 节）。
- **选择项** 以按钮形式显示，点击即可选中。
- **数值输入：** 输入后，点击键盘上方的【完成】（iPhone）或键盘上的确认键（Android）即可收起键盘。
- **输入错误：** 无效数值以红色显示并附简短说明，例如「请输入 0 到 100 的值。」
- **示例数值：** 为节省时间，新建实时评估时第 1 至 3 屏**已预先填入**一个合成示例病例，请按测试需要修改。第 4、5 屏为空白。

### 第 1/5 屏 — 受体状态

| 字段 | 输入 | |
|---|---|---|
| ER状态 | 阳性 / 阴性 | 必填 |
| PR状态 | 阳性 / 阴性 | 必填 |
| HER2状态 | 阳性 / 阴性 | 必填 |
| Ki-67 (%) | 0–100 | 必填 |

提示「管腔A型 < 14，管腔B型 ≥ 14」仅供参考，分子亚型由平台判定。

*请注意：HER2 目前只有「阳性」和「阴性」两个选项，尚无「2+，ISH 待定」（可疑）选项。按常规应记录为可疑的病例目前无法如实录入；如这会影响您的测试，请告知 CRIL。*

本页还显示【会话ID】，这是每次评估随机生成的编号，并非患者标识。

### 第 2/5 屏 — 肿瘤特征

| 字段 | 输入 | |
|---|---|---|
| 分期 | 0 至 IV 期，含亚分期 | 完整评估所需 |
| 分级 | 1、2 或 3 | 完整评估所需 |
| 组织学亚型 | IDC、ILC、DCIS 或佩吉特病 | 选填 |
| 淋巴结状态 | N0、N1、N2 或 N3 | 完整评估所需 |
| 年龄（岁） | 整岁，18–120 | 完整评估所需 |

### 第 3/5 屏 — 生物标志物与手术

| 字段 | 输入 | |
|---|---|---|
| CA 15-3 (U/mL) | 0 或以上 | 选填 |
| CEA (ng/mL) | 0 或以上 | 选填 |
| 手术日期 | YYYY-MM-DD（可填写未来日期） | 选填 |
| 贝叶斯增强 | 开启 / 关闭 | 选填 |

### 第 4/5 屏 — 合同字段
本屏及下一屏标有【仅限评估 · 临时字段】，其临床定义仍在审核中。

| 字段 | 输入 | |
|---|---|---|
| 肿瘤大小 | 大于 0 的数值。**单位尚未确定** | 完整评估所需 |
| 性别 | 女性 / 男性 / 其他 / 未知 | 选填 |

### 第 5/5 屏 — 其他合同字段

| 字段 | 输入 | |
|---|---|---|
| ECOG评分 | 整数，0–4 | 完整评估所需 |
| PD-L1状态 | 阳性 / 阴性 / 未检测 | 选填 |
| HER2低表达 | 阳性 / 阴性 / 未知 | 选填 |
| LVEF（%） | 0–100 | 选填 |
| 治疗意图 | 新辅助 / 辅助 / 未指定 | 选填 |

填写完毕后点击【复核】。

## 9. 复核与提交

【复核】页面在发送前列出全部数值。

- **红色提示框【完整评估所需】：** 列出您留空但平台需要的数值。点击「前往……」链接可直接跳转到相应页面，其他已填内容保持不变。**仍可提交。**
- **【示例数值，未修改】：** 标记您尚未修改的示例数值，便于区分您自己输入的内容。
- **【交付模式】：** 显示实时平台或合成演示（琥珀色）。
- **【基线】：** 只有平台状态为【已验证】时才能提交。

点击【编辑】返回第 1 屏，或点击【提交】发送病例。

提交实时病例时，服务会先确认平台仍为经批准的版本。如无法确认，**不会显示任何结果**，而是显示【服务不可用】及原因（例如平台与经批准的版本不匹配）。【重试验证】只会重新进行验证，绝不会重新提交您的病例。

*请注意：在不完整病例的已完成结果中（见第 10 节），可能出现平台自身的「ASSESSMENT BLOCKED」字样，两者不同。该结果仍会显示分子亚型、治疗方案和生物标志物，只是不显示风险。*

## 10. 查看结果

【评估结果】页面从上到下依次显示：

1. **【临床摘要】：**【分子亚型】和【风险】。风险以您所选语言的文字显示：高危、中危或低危。红色表示高危，绿色表示低危，其他为蓝色。另有一行说明结果来源（已验证的实时平台，或此前记录的合成结果）。
2. **【未达到完整评估】**（仅限不完整病例，见下文）。
3. **【警告和背景】：** 平台自身的提示信息，按原样以英文显示。
4. **【信息完整性】：** 完整性层级及缺失的数值和所在页面。
5. **【返回的治疗选项】：** 与平台原文完全一致。
6. **【返回的生物标志物结果】。**
7. **【分类置信度】：** 开启贝叶斯增强时显示。依赖此数值之前，请先阅读审核与测试清单 C7 节：它所对应的亚型可能与页面显示的亚型不同。
8. **【技术详情】：** 触发的规则、推理追踪、原始数值及平台版本。

### 病例不完整时
如您留空了平台需要的数值：
- **【未达到完整评估】** 列出缺失的数值及所在页面，例如「肿瘤大小（第 4/5 屏）」。
- **【风险】** 显示「暂不显示 — 需要……」。
- 分子亚型、治疗选项和生物标志物**仍会显示**。
- 点击【补全缺失字段】，应用将打开第一个缺失数值所在的页面，**已填写的内容全部保留**。补填数值后，进入【复核】并重新提交。

### 结果不会保存
结果仅在页面打开期间存在，不会写入手机存储。如需记录，请手工记下数值，或在所在机构允许的情况下截屏。

## 13. 提示信息及处理方法

| 您看到的内容 | 含义 | 处理方法 |
|---|---|---|
| 【正在检查…】 | 应用正在连接服务 | 请等待约 10 秒 |
| 【已在本设备登录】—「正在等待服务器……」 | 已配对，但暂时无法连接服务 | 检查网络；点击【重试检查】。无需邀请码 |
| 【服务器未连接】 | ACR 评估服务离线 | 稍后再试，或告知 CRIL。如可用，仍可使用【合成演示】 |
| 【网关已连接 — 实时平台离线】 | 服务在线，但 ACR 平台离线 | 使用【合成演示】，或稍后再试 |
| 【服务不可用】/【不匹配】 | 平台不是经批准的版本 | 请勿继续实时测试，并告知 CRIL |
| 「设备不正确。此设备未获此邀请码授权。」 | 该邀请码已与另一部手机配对 | 使用已配对的手机，或向 CRIL 申请新邀请码 |
| 「邀请码已过期。请申请新的邀请码。」 | 已超过 30 天有效期 | 向 CRIL 申请新邀请码 |
| 【演示病例已修改】（红色） | 演示病例的数值被修改 | 恢复原值，或切换到【实时平台】 |
| 「已验证的合成样例不可用。」 | 没有可用的演示记录 | 使用【实时平台】；或在已配对手机上点击【浏览全部五个页面】，查看页面但不生成结果 |
| 「请求过多。请等待后重试。」 | 短时间内尝试次数过多 | 等待几分钟 |
| 「评估结果不确定。」 | 未能清晰收到结果 | 请勿反复提交；记下时间并告知 CRIL |

## 14. 数据与隐私

- 邀请码绝不会被保存。您的评估会话和一个随机安装标识符仅保存在手机的安全密钥库中，断开访问时即被删除。
- 病例输入和结果仅保存在内存中，评估结束即被清除。
- 应用不含数据分析和广告，也不能通过网络直接更新：每次更改都是一个经过审核的新版本。
- 为保障安全，服务会记录技术事件（例如请求的时间和结果），但不会记录临床数值。
