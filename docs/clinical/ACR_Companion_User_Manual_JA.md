# ACR Companion：レビュアー向けユーザーマニュアル

**対象：** v0.6.7（Build 48）。お使いのバージョンは**About**画面に表示されます。
**更新日：** 2026年9月18日
**状態：** CRILにより招待評価用として承認済み。一般配布禁止。
**対象者：** 招待された臨床レビュアーおよびレビューテスター。
**中国語版：** ACR_Companion_User_Manual_ZH-CN。

---

## 1. 読み進める前に

- **合成データのみ。** 実患者の情報を、コード化・仮名化されたものであっても入力しないでください。本アプリは氏名や病院番号を要求しません。
- **臨床使用不可。** 結果は評価用の意思決定支援です。誰かの診断や治療に使用してはなりません。
- **本アプリには臨床ルールは含まれていません。** 結果に表示される内容はすべてACR Platformから来ています。アプリは入力内容を収集し、安全に送信し、回答を表示するだけです。
- **ルールの仕組み**（サブタイプ、リスク、治療ライン、ベイズ信頼度）は、 companion 文書『ACR Companion — ZZUレビュアー向けレビューおよびテストリスト』で説明されています。本マニュアルはアプリの使い方を説明します。

本マニュアルでは、**太字**は英語画面でのボタン名および画面名です。

## 3. アプリのインストール

**CRILがお使いの電話への入手方法を案内します。** CRILから送られたファイルまたはリンクのみをインストールしてください。

**Android**
1. CRILから送られたインストールファイル（`.apk`で終わる）を開きます。
2. 電話が求めたら、この提供元（ブラウザやファイルマネージャーなど）からのインストールを許可します。XiaomiやSamsungなど一部の電話では追加のセキュリティ確認が表示されるので、続行を選びます。
3. インストール完了後、**ACR Companion**を開きます。

**iPhone**
iPhoneへのインストールはCRILが別途手配します。初回起動時に開発者を信頼するよう求められる場合があります：*設定 → 一般 → VPNとデバイス管理*で信頼してください。

以前のバージョンがすでにインストールされている場合、上書き更新するか先に削除するかをCRILが指示します。

## 5. アプリを開いて言語を選ぶ

1. アプリを開きます。**評価アクセス**から始まります。
2. 言語を変更するには、**戻る**をタップしてウェルカム画面に移動し、**言語**をタップして選択します。すべての画面が選択に従います。アラビア語は右から左に読みます。
3. ウェルカム画面には**About**もあり、ACR Platformの説明とアプリのバージョンを表示します。
4. ウェルカム画面で数秒待つと、1ページの紹介ポスターが表示されます。横にスワイプすると**プライバシーとCookies**の通知が表示され、**詳細を読む**でこのマニュアルを電話で開けます。上にスワイプして続行します。
5. **理解しました — 開始**をタップして**評価アクセス**に戻ります。

## 6. 初回接続

1. **評価アクセス**で**招待コード**にコードを入力します。
2. **安全に接続**をタップします。
3. メッセージが確認します：*「招待コードが承認され、このモバイルデバイスとのみペアリングされました。30日間有効です。」* ペアリング日と有効期限（UTC）も表示されます。**続行**をタップします。
4. **次へ**をタップして評価を開始します。

**注意：**
- **コードは1台の電話でのみ機能します。** 最初に入力した電話とペアリングされます。他の電話では*「不正なデバイスが使用されました。」*と表示されます。
- **アクセスはペアリングから30日間**有効です。その後、*「招待コードの有効期限が切れました。新しいコードを申請してください。」*と表示されます。CRILに新しいコードを依頼してください。
- **コードの入力は1回だけです。** その後はアプリを開くたびに自動再接続します。再入力が必要なのは**アクセスを切断**した後だけです（セクション12）。30日間はリセットされません。
- コード自体は電話に保存されません。

### 接続パネル
同じ画面の**接続証拠**に表示されます：
- **ゲートウェイ：** **接続済み**、**サーバー未接続**、**確認中…**
- **ベースライン証明：** **VERIFIED**はACR Platformが承認版と完全に一致し、ライブ結果を生成できることを意味します。**MISMATCH**または**UNAVAILABLE**はライブ結果がブロックされることを意味します。

## 7. Live platform または Synthetic demonstration

開始前に**配信モード**で選択します：

| 選択 | 起こること | 用途 |
|---|---|---|
| **Live platform**（青） | 入力がACR Platformに送られ、臨床ルールが今適用されます | すべての実テストケース |
| **Synthetic demonstration**（琥珀色） | ルールは実行されません。アプリが固定のデモ症例を入力し、サービスがその症例について以前にライブプラットフォームから記録された結果を表示します | 完全な結果を簡単に見る、またはライブプラットフォームがオフラインのとき |

デモモードでは**値を変更しないでください**。変更すると、レビューに赤い**デモ症例が変更されました**ボックスが表示され、結果は返りません。

## 8. 症例の入力

### 一般ヒント
- **必須項目：** 画面1のER、PR、HER2、Ki-67のみ。Ki-67が0〜100の数値になるまで**次へ**は使用できません。
- **その他はすべて任意**ですが、一部の値は**完全評価に必要**と表示されます。なくてもプラットフォームは回答しますが、リスクは保留されます（セクション10）。
- **選択肢**はボタンです：タップして選択します。
- **数値：** 入力後、キーボード上の**完了**（iPhone）またはキーボードの確定/完了キー（Android）をタップしてキーボードを閉じます。
- **誤り：** 無効な値は赤で短い説明とともに表示されます。例：*「0から100の値を入力してください。」*
- **サンプル値：** 時間短縮のため、新しいLive評価の画面1〜3は合成サンプル症例で**すでに入力済み**で開きます。テストに合わせて変更してください。画面4と5は空で開きます。

### 画面1/5 — 受容体ステータス

| 項目 | 入力 | |
|---|---|---|
| ER status | positive / negative | 必須 |
| PR status | positive / negative | 必須 |
| HER2 status | positive / negative | 必須 |
| Ki-67 (%) | 0–100 | 必須 |

ヒント*「Luminal A < 14, Luminal B ≥ 14」*は参考のみで、サブタイプはプラットフォームが決定します。

*注意：HER2は現在PositiveまたはNegativeのみです。「2+, ISH pending」（equivocal）の選択肢はまだありません。通常equivocalとして記録される症例は現時点ではそのように入力できません。テストに影響する場合はCRILに知らせてください。*

画面には**セッションID**も表示されます。これは各評価用に作成されるランダムな参照で、患者識別子ではありません。

## 9. レビューと送信

**レビュー**は送信前にすべての値を一覧表示します。

- **赤いボックス「完全評価に必要」：** 空欄のままにしたが必要な値を一覧表示します。**…へ移動**リンクをタップするとその画面にジャンプし、他の入力は保持されます。**それでも送信できます。**
- **「サンプル値、未変更」：** 変更していないサンプル値に印が付き、自分の入力と区別できます。
- **配信モード：** LiveまたはSynthetic demonstration（琥珀色）を表示します。
- **ベースライン：** プラットフォームが**VERIFIED**のときのみ送信できます。

**編集**で画面1に戻るか、**送信**で症例を送ります。

Live症例を送信すると、サービスはまずプラットフォームが承認版のままか確認します。確認できない場合、**結果は表示されません**。**Service unavailable**と理由が表示されます。**Retry verification**は確認だけを繰り返し、症例を再送信しません。

*注意：不完全な症例の完了結果内に表示されることがあるプラットフォーム自身の「ASSESSMENT BLOCKED」という文言とは異なります。その結果でもサブタイプ、治療ライン、バイオマーカーは表示され、リスクのみ保留されます。*

## 10. 結果を読む

**評価結果**画面は上から順に表示します：

1. **臨床概要：** **分子サブタイプ**と**リスク**。リスクはあなたの言語の語です：HIGH、INTERMEDIATE、LOW。赤は高、緑は低、青はその他。結果の出所（検証済みライブプラットフォーム、または以前に記録された合成結果）を示す行があります。
2. **完全評価に到達せず**（不完全症例のみ；下記参照）。
3. **警告と文脈：** プラットフォーム自身のメッセージをそのまま英語で表示。
4. **情報完全性：** 完全性ティアと不足値、画面番号。
5. **返された治療オプション：** プラットフォームが書いたとおり。
6. **返されたバイオマーカー結果。**
7. **分類信頼度：** ベイズ拡張がONのとき表示。この数値に依拠する前にレビューおよびテストリストのC7節を読んでください：表示されたサブタイプとは異なるサブタイプを指す場合があります。
8. **技術詳細：** 発火したルール、推論トレース、生値、プラットフォームバージョン。

### 症例が不完全なとき
プラットフォームが必要とする値を省略した場合：
- **完全評価に到達せず**が不足値と画面を挙げます。例：*「Tumour size（画面4/5）」*。
- **リスク**は*「保留 — …が必要」*と表示。
- サブタイプ、治療オプション、バイオマーカーは**引き続き表示**。
- **不足フィールドを補完**をタップ。最初の不足値の画面が開き、**入力済みの内容はすべて保持**されます。値を追加し、**レビュー**に進み再送信します。

### 結果は保存されません
結果は画面が開いている間だけ存在します。電話のストレージには何も書き込まれません。記録が必要な場合は手で値を控えるか、組織が許可する場合はスクリーンショットを撮ってください。

## 13. メッセージと対処

| 表示 | 意味 | 対処 |
|---|---|---|
| **確認中…** | アプリがサービスに接続中 | 約10秒待つ |
| **このデバイスでサインイン済み** — *「サーバーを待っています…」* | ペアリング済みだがサービスに到達できない | インターネットを確認；**再確認**をタップ。招待コード不要 |
| **サーバー未接続** | ACR評価サービスがオフライン | 後で試すかCRILに連絡。提供されていれば**Synthetic demonstration**を使用可 |
| **ゲートウェイ接続済み — Live Platformオフライン** | サービスは稼働中だがACR Platformが停止 | **Synthetic demonstration**を使用、または後で試す |
| **Service unavailable** / **MISMATCH** | プラットフォームが承認版でない | ライブテストを続けない；CRILに連絡 |
| *「不正なデバイスが使用されました。」* | コードが別の電話とペアリング済み | ペアリング済みの電話を使うか、CRILに新コードを依頼 |
| *「招待コードの有効期限が切れました。新しいコードを申請してください。」* | 30日経過 | CRILに新コードを依頼 |
| **デモ症例が変更されました**（赤） | デモ値が変更された | 元に戻すか、**Live platform**に切り替える |
| **検証済み合成フィクスチャは利用できません。** | 記録済みデモがない | **Live platform**を使用；またはペアリング済み電話で**5画面すべてを順に表示**し、結果なしで画面を見る |
| *「リクエストが多すぎます…」* | 短時間に試行しすぎ | 数分待つ |
| *「評価結果が不確実です。」* | 回答が明確に届かなかった | 繰り返し送信しない；時刻を記録しCRILに連絡 |

## 14. データとプライバシー

- 招待コードは保存されません。セッションとランダムなインストール識別子は電話のセキュアキーストアにのみ保持され、切断時に削除されます。
- 症例入力と結果はメモリ内のみに保持され、評価終了時に消去されます。
- アプリには分析も広告もなく、無線更新もできません：すべての変更は新しいレビュー済みバージョンです。
- サービスは安全維持のため技術イベント（リクエストの時刻と結果など）を記録します；臨床値は記録しません。

## 17. 用語

| 用語 | 意味 |
|---|---|
| ACR Platform | 医学知識モデルとルールを保持し、結果を生成するサーバー |
| Gateway | アプリとACR Platform間の安全なサービス |
| Baseline / attestation | プラットフォームが承認版と完全に一致するかの確認 |
| Tier | 症例の完全度：1または2はリスク保留；3は完全評価 |
| Synthetic | 患者由来ではない、作られたテストデータ |
| Bayesian enhancement | ルールベース結果に追加される任意の確率推定 |
